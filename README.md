## 📖 课程简介

本仓库是《数据库原理实验》课程的全学期作品集，用于存放 16 周实验的源代码、实验报告与数据文件。

## 📝 每周实验记录规范（建议）

每个 `WeekNN/` 目录里建议放以下内容：

| 文件 | 说明 |
| :--- | :--- |
| `README.md` | 本周实验的目标、步骤、遇到问题与总结 |
| `*.sql` | 本周用到的建表、查询语句 |
| `report.pdf` / `report.md` | 实验报告 |
| `screenshot/` | 关键运行结果的截图 |
